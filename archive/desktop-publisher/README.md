# Archived Desktop Publisher

This directory contains the archived prototype React/Vite desktop publisher for Adrienne Zoo.

## Status

**Retired / Archived.**

The Adrienne Zoo project has consolidated around its native Android companion app (`android_companion_app/`). The desktop publisher is no longer a user-facing product or a required build step.

Wildlife research datasets, provenance, licensing, reproducible content generation tools, and `.wildpack` compatibility fixtures have been retained in the project root (`data/`, `fixtures/`, `tools/`).
